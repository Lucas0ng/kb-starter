# 入库与回流细则

知识库能不能“自己长”，取决于回流做没做。只入库不回流，知识库只会变大，不会变聪明。

## 入库

1. `KB scan <新资料> --out <工作目录> --kb <知识库>`：已入库的文件会被标成“已入库”，不会重复复制。
2. 处理待AI条目、给用户确认、`KB apply`，同建库流程。
3. 入库只把文件放到 A/D 层。接下来按文件类型做回流。

## 按类型回流

材料怎么写成卡片（文献、决策、问题、SOP、人物、教训、概念）见 [蒸馏流程.md](蒸馏流程.md)。下表是入库后各类材料的去向：

| 新入库的是 | 做什么 |
|---|---|
| 论文 | 用户要精读的，按 `模板_文献卡片` 建卡，放 `01_知识提炼/文献卡片/<项目>/`。环境里有专门的论文精读 skill 时优先用它，再按模板补“与我课题的关系”和“回流”两节。不精读的只在资料索引里留着。 |
| 实验记录、数据、照片 | 按 `模板_实验记录` 整理成记录笔记，放在原始文件旁边；用户的原话原样保留。更新对应 SOP 的“现行操作”（如果操作变了）和项目总览的“当前状态”。 |
| 会议记录 | 把导师或合作者的指示整理进项目的决策记录或总览；原话保留在原文件。 |
| 课程资料 | 一般不回流；用户要求复习或总结时再提炼。 |
| 用户的产出（论文稿、PPT、报告） | 在项目总览的“现行执行文件”或成品索引里登记；里面有新结论、新方法时，写回概念节点和 SOP。 |

## 写回概念节点（每次必做）

每次任务结束，挑出 **1–3 条** 以后还会用到的结论：

- 已有对应概念节点：在“关键事实与数字”里加一条或改写一条，带来源链接；被推翻的旧说法改写，并在“修订记录”里留一行。
- 没有对应节点，且这个概念在两处以上出现过：按 `模板_概念节点` 新建。
- 只出现一次的：先不建，体检时如果反复出现会被提出来。

判断“值得写回”的标准：换一个任务时还会用到；或者推翻、修正了已有的说法。

## 更新假设台账

结果支持或否定了哪条假设，就改 `01_知识提炼/研究问题/假设台账.md` 里的状态和证据，并在“状态变化记录”追加一行。出现了新假设就加一行，状态“待测”。

## 变更日志与索引

`apply` 会自动记一行 `[入库]`。蒸馏和回流改了哪些笔记，由你在同一天的标题下补带标签的行，例如：

```
- [蒸馏] [[Zhang2025.pdf]] → [[Zhang2025 · 电解液添加剂]]；另 2 篇同批文献建卡
- [回流] 更新概念节点 [[SEI 膜]]（加入 Zhang 的 45 % 容量保持率）；假设台账 H3 待测 → 支持（弱）
```

最后运行 `KB index` 更新知识索引，新卡片才会出现在 AI 开工先读的索引里。
