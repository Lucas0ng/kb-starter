# 纲要访谈细则

知识库的主线只有用户知道：为什么建这个库、有哪些项目、每个项目要回答什么问题、哪份文件算数。AI 读完资料能整理事实，但写不出这些判断。所以建库第一步先访谈，把答案写成 `知识库纲要.md`，后面分项目、写总览、做体检都以它为准。

## 先问有没有现成的大纲

大多数用户手上已经有“大纲”：开题报告、项目申请书、任务书、导师或领导布置任务的消息、最近一次汇报 PPT、课程大纲。**有的话先从材料起草，用户只改，不用从零回答。** 这一步对用户最省事，也最接近真实情况：先有大纲，再有知识库。

做法：

1. 读用户指定的材料（或在资料文件夹里找名字含“开题”“申请书”“任务书”“计划”“大纲”的文件，问用户是不是它）。
2. 按下面的纲要格式起草，材料里没有的字段写“待确认”。
3. 把草稿发给用户，只问草稿里标了“待确认”的地方，以及“还有没有材料里没写到的项目”。

## 没有材料时：一轮问完的五个问题

一次发出，不要一题一题来回问。允许用户答“跳过”或“不知道”。照抄下面这段即可，括号里的例子按用户的身份换（研究生、上班族、备考学生）：

```text
建库前想先花两分钟了解这个知识库要做什么，这决定资料怎么分组、项目总览怎么写。能答多少答多少，不知道的写“跳过”。

1. 这个知识库主要用来做什么？
   （例：读研做课题和上课；准备考研；工作上几个客户项目的资料）
2. 现在有哪几个项目、课题或课程？每个用一句话说目标。
   （例：电解液添加剂——找到能让电池在 4.4 V 下稳定循环的添加剂）
3. 每个项目做到哪一步了？下一步打算做什么？
   （例：第 1 轮筛选做完，下周做 4 组对照）
4. 每个项目最想回答的 1–3 个问题是什么？
   （例：添加剂浓度多少最好？为什么高电压下会失效？）
5. 有没有现成的大纲材料，比如开题报告、申请书、任务书、最近一次汇报 PPT？
   有的话告诉我文件名，我先从里面起草，你只需要改。
```

用户说“直接建，别问了”时：不再追问，按文件夹名和文件内容起草一份最小纲要（只有项目名和关键词，其余写“待确认”），照常建库，汇报时提醒“纲要还缺目标和核心问题，有空补上，总览和体检会更准”。

## 从回答到纲要

| 回答 | 写进纲要的哪里 |
|---|---|
| 第 1 题 | 「这个知识库用来做什么」 |
| 第 2 题 | 每个项目一节：`### 项目：名称`、「一句话目标」；课程用 `### 课程：名称` |
| 第 3 题 | 「现在在哪一步」「下一步」 |
| 第 4 题 | 「核心问题」（编号列表）；同时作为假设台账的第一批条目 |
| 第 5 题 | 「大纲来源」；有材料就从材料补全其他字段 |

**关键词由你来提，用户确认。** 从用户的回答和资料文件夹里的文件名、子文件夹名里，给每个项目挑 4–10 个词：课题里的专有名词、材料和方法名、常见英文写法、用户习惯的简称。不要用“实验”“数据”“论文”这种所有项目都会出现的词。扫描后看 `plan.md` 的“识别到的项目”：还有很多文件没分到项目时，补关键词再扫一次。

**别名**写同一项目的其他叫法：旧文件夹名、英文名、导师口中的叫法。资料里子文件夹名和别名一致时，文件直接归到这个项目。

## 纲要的规矩

- **用户定，AI 提议**：纲要的目标、核心问题、项目增删，只有用户确认后才改。AI 发现纲要过时（项目阶段变了、出现了纲要外的新方向），在体检报告里提议，用户勾选后再改，并在「修订记录」里记一行。
- **短**：每个项目十行以内。细节放项目总览和卡片，纲要只放主线。
- **会变**：课题转向、新开项目时更新纲要，比每次在对话里解释一遍省事。

## 示例

### 研究生（课题 + 综述 + 课程）

```markdown
## 这个知识库用来做什么

读研期间的课题资料、综述写作和课程笔记，主要服务毕业论文。

## 谁会读它

- 我自己；Claude Code 帮我整理资料、写综述时读；组会前粘给网页版 AI 帮我理思路。

## 项目

### 项目：电解液

- 一句话目标：筛选能让锂电池在 4.4 V 下稳定循环的电解液添加剂，并解释界面机制
- 现在在哪一步：第 1 轮添加剂筛选做完，循环数据在整理
- 下一步：按导师要求做 4 组浓度对照
- 核心问题：
  1. 添加剂浓度多少时循环最稳？
  2. 高电压下容量衰减主要来自正极界面还是电解液分解？
- 关键词：电解液、添加剂、LiPF6、FEC、截止电压、循环、扣电、electrolyte、additive
- 别名：电解液实验、battery
- 大纲来源：开题报告_v2.docx

### 项目：综述

- 一句话目标：写一篇固态电解质综述，投 RSER
- 现在在哪一步：初稿 v3 完成，等导师意见
- 下一步：按意见补第 4 节
- 核心问题：
  1. 固态电解质的界面问题有哪些主流解决思路？
- 关键词：固态电解质、solid-state、review、综述
- 别名：固态综述
- 大纲来源：访谈

### 课程：高分子物理

- 一句话目标：期末考试和课程作业
- 现在在哪一步：第 4 讲
- 关键词：高分子物理、polymer physics、橡胶弹性
- 大纲来源：访谈

## 不收的东西

- 生活照片、证件扫描
```

```markdown
## 项目

### 项目：A 公司官网改版

- 一句话目标：10 月底前上线新版官网，首页加载时间降到 2 秒以内
- 现在在哪一步：设计稿确认完，开发第 2 周
- 下一步：周五和客户过一遍首页
- 核心问题：
  1. 客户最在意的是哪三个页面？
  2. 图片 CDN 用哪家，费用谁出？
- 关键词：A公司、官网、改版、首页、CDN、设计稿
- 别名：A司、官网项目
- 大纲来源：项目合同附件《需求说明书》
```
