## 阅读顺序（先蒸馏，后原文；够用即停）

0. [[知识库纲要]]：这个知识库为什么存在、有哪些项目、每个项目要回答什么问题。由你定。
1. [[知识索引]]：这个知识库已经知道什么，每条一行。AI 每次开工先读它。
2. 本导航；要新增、移动或分类文件时再读 [[知识库说明]]。
3. 相关的 `<项目>_总览`。
4. B 层：概念节点、文献 / 决策 / 问题 / 教训 / 人物卡片、[[假设台账]]、[[缺口清单]]。
5. C 层：SOP、方案、模板。
6. D 层：成品和索引。
7. A 层原文只在上面不够时，经 [[资料索引]] 定位后再读。

## 换 AI 怎么办

- **Claude Code / Codex / Cursor**：在本文件夹打开即可。它们会读 `AGENTS.md`（Claude Code 读 `CLAUDE.md`，已指向 `AGENTS.md`）。
- **网页版 ChatGPT / DeepSeek / Kimi 等**：把 `99_工作区/粘贴包/` 里最新的粘贴包整个粘过去。没有的话，让本地 AI 生成一个。
